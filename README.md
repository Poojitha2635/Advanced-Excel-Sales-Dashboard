# Advanced Sales Dashboard using Microsoft Excel

##  Project Overview
This project focuses on building an interactive Sales Dashboard using Microsoft Excel. The dashboard provides insights into sales performance, revenue, profit, customer behavior, and product performance through dynamic reports and visualizations.

--

## Objectives
- Clean and prepare sales data.
- Analyze sales performance.
- Build interactive dashboards.
- Track KPIs.
- Support business decision-making.

--

##  Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Advanced Excel Formulas

---

## Dataset
Sales Dataset (.xlsx)

---

# Project Workflow

### Step 1: Data Collection
- Imported the sales dataset into Excel.

### Step 2: Data Analysis
- Created Pivot Tables.
- Applied advanced formulas.
- Calculated KPIs.

### Step 3: Dashboard Development
Created an interactive dashboard with:
- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Sales by Region
- Sales by Category
- Sales by Product
- Monthly Sales Trend
- Top 10 Products
- Top Customers
- Profit by Category

### Step 4: Interactive Features
- Region Slicer
- Category Slicer
- Year Filter
- Dynamic Pivot Charts

- Best-performing products.

- Most profitable categories.
